# Sicurezza

KeePassMobile gestisce password: le segnalazioni di sicurezza sono benvenute e vengono trattate
con priorità.

## Come segnalare una vulnerabilità

- **Non aprire una issue pubblica.**
- Usa **Security → Report a vulnerability** nella pagina GitHub del progetto (segnalazione privata).
- Descrivi versione, piattaforma (Android o iOS, versione del sistema), passi per riprodurre e
  impatto.
- **Non allegare database reali**, password o file chiave: usa un database di prova con dati
  finti.

Riceverai una risposta entro 7 giorni. Dopo la correzione la vulnerabilità viene resa pubblica
insieme alla versione che la risolve, con i crediti a chi l'ha segnalata (se lo desidera).

## Versioni supportate

Solo l'ultima versione pubblicata riceve correzioni di sicurezza.

## Ambito

Fanno parte dell'ambito: cifratura e decifratura dei database, gestione delle chiavi (anche
biometriche), dati sensibili in memoria, su disco, negli appunti o nei log,
protezione dello schermo e della sessione.

Sono fuori ambito i dispositivi con root o jailbreak e gli attacchi che richiedono il telefono
sbloccato in mano all'attaccante con l'app già aperta.
